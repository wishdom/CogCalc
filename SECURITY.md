# Security policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/wishdom/CogCalc/security/advisories/new) to report a suspected security issue. Avoid posting sensitive details in public issues, discussions, or pull requests before a fix and disclosure have been coordinated.

Include, where available:

- The affected CogCalc version or commit and operating system.
- Steps to reproduce, including a minimal example or proof of concept.
- The potential impact and any suggested mitigation.

Remove credentials and personal information from logs and attachments. When possible, check whether the issue affects the latest code on `main`, but do not delay a report if you cannot reproduce it there.

Use the private report to coordinate a fix and public disclosure. For ordinary bugs and usage questions, use [issues](https://github.com/wishdom/CogCalc/issues) or [Discussions](https://github.com/wishdom/CogCalc/discussions).
